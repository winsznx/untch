# Dashboard

URL: [www.untch.xyz/dashboard](https://www.untch.xyz/dashboard)

The dashboard is the operator surface. It is not the money path. Agents and Guard talk to the ASP and chain. You use the dashboard to set policy, answer escalations, and inspect history.

## Sign in

1. Connect a wallet (OKX first).
2. Switch to **X Layer mainnet** when prompted.
3. Sign the SIWE message.

Sessions bind identity only. Every on-chain write still needs its own wallet signature.

## Screens

| Path | Purpose |

| `/dashboard/disputes` | Dispute packets |
| `/dashboard/settings` | Operator settings and channel bindings |

## Data scope

Reads are scoped to your wallet as policy owner. You do not see another operator’s agents or ledger.
