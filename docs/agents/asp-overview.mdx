# ASP overview

Untch is listed and operated as an **A2MCP** ASP:

- Pay-per-call tools
- Fixed prices in USDT0
- Settlement through OKX x402 on X Layer mainnet
- No per-task escrow negotiation

Base URL:

```text
https://asp.untch.xyz
```

Catalog (free JSON):

```text
https://asp.untch.xyz/catalog
```

## Who calls it

- Buyer agents in any framework
- Untch Guard middleware
- Your own automation and tests

Humans use the [dashboard](https://www.untch.xyz/dashboard) and [docs](https://docs.untch.xyz). Agents use the ASP.

## ERC-8004 card

```text
https://asp.untch.xyz/agent-registration.json
https://asp.untch.xyz/.well-known/agent-registration.json
```

Image: `https://www.untch.xyz/brand/untch-icon-2048.png` (1:1). After mainnet Identity `register()`, set `ERC8004_AGENT_ID` so `registrations[]` links the NFT.

## Compatibility

Per OKX Agent Payments Protocol guidance for A2MCP, sellers are plain priced HTTP services. Untch does not require a seller-side MCP protocol wrapper for listing validity. Buyers may wrap tools in MCP on their side. The ERC-8004 card declares `x402Support: true` and OASF skills. It does not claim a formal MCP JSON-RPC host.
