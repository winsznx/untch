## Key decisions (recorded per D0.4 brief)

- **solc pin** → `solc = "0.8.34"` in [foundry.toml](../../contracts/foundry.toml): the latest
  stable 0.8.x available locally on 2026-07-09. Foundry fetches this exact patch via svm.
- **optimizer** → `optimizer = true`, `optimizer_runs = 200` (documented balanced baseline;
  revisit against measured gas before mainnet). `via_ir = false`, documented and constant
  across test/deploy per §28.
- **warnings-as-errors** → the brief's `deny_warnings = true` in its current, non-deprecated
  spelling `deny = "warnings"` (Foundry 1.6.0 deprecated the old key). **Verified live:** an
  injected unused-variable warning failed `forge build`.
- **evm_version = `paris`** → conservative default. X Layer's official docs
  (`web3.okx.com` / `www.okx.com`) are network-unreachable from this environment (HTTP 000,
  same blocker as D0.3), so the exact hardfork X Layer supports could **not** be confirmed
  from an official source today. `paris` emits no PUSH0/transient-storage opcodes, so bytecode
  stays portable on a zkEVM L2. **D0 FOLLOW-UP:** confirm X Layer's EVM version from official
  docs (or probe PUSH0/TSTORE via testnet RPC) before mainnet; may be raised only after the
  §28 fork-integration stage proves it on an X Layer testnet fork.
- **Aderyn install** → `cargo install aderyn` (cargo was available → task's primary path).
  Resolved crates.io latest `0.1.9`. Aderyn nags to prefer the Cyfrin installer; the cargo
  build is functional. CI pins `--version 0.1.9 --locked` to match this evidence.
