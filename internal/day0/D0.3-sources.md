# D0.3 — X Layer constants: sources of record

**Gate:** §29 D0.3 · resolves §23 **Q5** (USDG contract address + decimals). Backs `packages/shared/src/chains.ts`.
**Date checked:** 2026-07-09 · **Owner:** Tim (@winsznx)
**Rule:** every constant below was read from an official source (OKX/X Layer, the canonical EVM chain registry, the official block explorer, or the token issuer) **or** read directly from the chain via JSON-RPC. Anything not confirmable from an official source is marked **UNCONFIRMED** and carries `address: null` in `chains.ts` — never guessed, never copied from a forum/aggregator.

## Verification methods (referenced below)

- **[chain]** — read directly from the network over JSON-RPC. Most authoritative for `chainId`, and for a token's own `symbol()/decimals()/name()`. Endpoints: mainnet `https://rpc.xlayer.tech`, testnet `https://testrpc.xlayer.tech` (both reachable and responding from this environment).
- **[registry]** — canonical `ethereum-lists/chains` entry (powers chainid.network / chainlist.org): `https://raw.githubusercontent.com/ethereum-lists/chains/master/_data/chains/eip155-<id>.json`.
- **[explorer]** — OKLink, the official X Layer block explorer.
- **[issuer]** — the token's official issuer (Paxos / Global Dollar for USDG).
- **[okx]** — OKX first-party docs/learn pages.

> **Environment caveat:** `web3.okx.com` / `www.okx.com` are network-unreachable from this build environment (HTTP `000`, same as D0.1). OKX-hosted pages below were read via server-side fetch (WebFetch) where possible; the OKX RPC mirrors (`*.okx.com`) could not be probed from here but are listed in the canonical registry. This did **not** block any constant — chainIds and token identities were confirmed on-chain, and the working RPCs/explorer are the `.xlayer.tech` / `oklink.com` hosts.

**USDT note (§23 Q3 overlap):** the plainly-labeled "USDT / Tether USD" on X Layer is the legacy wrapped token `0x1E4a…D41d`, which OKX is phasing out in favor of **USDT0** `0x779D…3736` (symbol `USD₮`). Both are confirmed and exported; which one the vault `tokenAllow` and x402 settlement use is a D0.1/contracts decision, not a D0.3 fact — both addresses are provided so that decision is made against verified values.

**USDG note (resolves §23 Q5):** confirmed from three independent official sources that agree on the same address — the issuer's own developer page, the official explorer's label, and the deployed contract's own `symbol()/name()`. Decimals on X Layer are **6** (read on-chain), not the 18 that USDG uses on some other chains — this is exactly why decimals were read per-network rather than assumed.
